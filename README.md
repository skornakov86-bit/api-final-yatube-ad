# API для проекта Yatube

Финальная версия API для социальной сети Yatube. 
Позволяет работать с постами, комментариями, подписками и группами.

## Как запустить:
1. Установить зависимости: `pip install -r requirements.txt`
2. Выполнить миграции: `python manage.py migrate`
3. Запустить сервер: `python manage.py runserver`
